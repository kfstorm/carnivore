# Domain Docs

## Before exploring

- Read root `CONTEXT.md` when it exists.
- Read root `CONTEXT-MAP.md` when it exists, then the relevant referenced context files.
- Read ADRs under `docs/adr/` that touch the work area.

If these documents do not exist, proceed without flagging their absence. Create them only when a real terminology or architectural decision needs recording.

## Layout

This is a single-context repository. Domain documentation uses root `CONTEXT.md` and `docs/adr/`.

## Vocabulary

Use terms defined in `CONTEXT.md` consistently in issues, specifications, tests, and implementation. Surface any conflict with an existing ADR instead of silently overriding it.
